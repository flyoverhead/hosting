# `timeweb`

`Timeweb Cloud` hosting provider configuration

API documentation: <https://timeweb.cloud/api-docs>

## Role variables

| Variable | Description | Example |
| :--- | :--- | :--- |
| `timeweb_account` | Timeweb Cloud account configuration | Example in [defaults](defaults/main.yml) |
| `timeweb_server` | VDS/VPS server configuration | Example in [defaults](defaults/main.yml) |

## Inventory

```yaml
timeweb:
  hosts:
    ru:
```

## Playbook

```yaml
- hosts: ru
  roles:
      - role: timeweb
```

## Variables

```yaml

timeweb_account:
  url: https://api.timeweb.cloud/api/v1
  api_key: <account_api_token> # Bearer token, https://timeweb.cloud/my/api-keys
  location: ru-1 # ru-1, ru-2, ru-3, kz-1, pl-1, nl-1

timeweb_server:
  cpu: 1
  name: ru-server
  os_name: debian
  os_version: '12'
  ssh_key: id_ed25519
  state: present
```

## Notes

- The cheapest preset matching `location` and `cpu` is selected automatically
- The root password is generated by Timeweb Cloud, access is provisioned via `ssh_key`
- Deletion moves the server to quarantine unless immediate deletion is enabled in the account settings
